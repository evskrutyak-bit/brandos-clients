Раздел 1

Суть проекта — 7 выводов после M2

Каждый вывод — итог 1–5 исследований. Не гипотезы — факты.

01

Реальное поле — 14 игроков, не 2 300

Остальные 1 500–1 800 одиночек на Авито — фоновый шум. Юля сейчас по чеку 8–15 тыс. ₽ в нижней половине стандарта. До премиума — не один шаг, а два.

02

Маржа — от сценария, не от часов

Soxspace: 50 тыс. ₽ пакет, маржа 30–46%. BankaBanka: 51 тыс. за 7 ч. Letspartyloft: 170 тыс. Новый год. Юля сейчас продаёт часы. Это центральный продуктовый разрыв.

03

Линейка — «событие × вариант», не уровни

Клиент ищет «лофт под выпускной», а не «лофт стандартного уровня». У Юли сейчас почасовка без пакетов — линейку строим с нуля в M3-02.

04

Главный триггер доверия — «залог вернут»

Подтверждается в 4 из 5 сегментов ЦА, рынком РФ и мировой практикой. Только 3–5 из 28 площадок публикуют правила открыто. Самая дешёвая стратегическая победа — переписать описания 14 лофтов за день.

05

Корпоратив под ключ — экономическое ядро

75 000 ₽ × 8 корпоратов/мес × 5 точек = до 3 млн ₽/мес в одном продукте. 5-кратное подтверждение: рынок, конкуренты, ЦА, мир, продукт.

06

База в телефоне — главный дешёвый рычаг

Повторные клиенты приходят сами — без программы, без напоминаний. Перевести базу из телефона в AmoCRM, сегментировать, запустить Telegram-рассылку — самый дешёвый рост 2026.

07 · Пустая клетка: угол для Юли

«Без хаоса, по уму» — это формат «под ключ» в среднем-плюс. Эта клетка занята четырьмя сильными игроками (BankaBanka, Multiroom, Letspartyloft, Campus Loft). Войти пятой без угла — стать ещё одной средней площадкой. Реальная пустая клетка: «семейный праздник под ключ с премиальным сервисом» + «камерный B2B 25–40 гостей» + «местный лидер района Бауманской».

Сверх-вывод

Юля по операционке (7 лет без срывов, 14 лофтов, AmoCRM) — уже Кластер B верхней половины. По упаковке (нет пакетов, 100% агрегаторы, база в телефоне, нет Telegram-канала, сайт без брони) — Кластер C, где идёт ценовая война. Стратегия: не «расти», а конвертировать невидимый капитал в видимый. Главный фокус 2026 — загрузка будней, апсейлы, альтернативные каналы.

7 сквозных выводов (≥3 исследований)

17,8% спроса, растёт. Самый высокий чек (50–80 тыс. с кейтерингом). На рынке нет пакета «корпоратив под ключ». Ни один из 11 разобранных брендов не работает с B2B системно (кроме AG Loft с большими залами 200+).

×4Прозрачность — входной билет в доверие, не плюс к сервису

Универсальная боль 4 из 5 сегментов. Только 3–5 из 28 площадок публикуют правила открыто. 35% негативных отзывов рынка — про скрытые платежи. Самая дешёвая стратегическая победа.

×4Скорость первого ответа (<15 мин) — главная точка обрыва сделки

«Вопрос задаёшь утром — отвечают вечером» в 2 из 5 сегментов. Медиана рынка — 30 мин, 35% негатива про связь. Узкая задача «первый ответ + ночной ответ + поддержание контакта» закрывается Telegram-ботом технически просто.

×4Сайт с прямой бронью — технологический минимум

Собственный сайт — ключевой маркер профессионализма. Онлайн-календари — стандарт. Фотографы и корпораты сравнивают лофт с бронированием отеля. Без сайта — остальные шаги теряют 50% эффекта.

×4Партнёрская экосистема 5–8 подрядчиков — главный рычаг роста чека без CAPEX

Апселлы +30–40% к выручке через стандартизированную матрицу (кейтеринг, DJ, фотограф, аниматор, декор). Soxspace, BankaBanka, Memory Place — норма кластера формата под ключ. Прямая копия без CAPEX.

×4База повторных продаж — главный недомонетизированный актив

Норма рынка ~10% повторов; программ лояльности почти нет. У Юли база в телефоне, не в AmoCRM, без рассылок. Мамы координируются в чатах — реферальная механика их естественная среда. Самый дешёвый рост — через существующую базу.

Команда 4 человека: Юля + менеджер + ночной админ + техник. AmoCRM на входящих, сайт без брони, Telegram-канала нет. Раздел 7

Что отсечено и где пробелы

Отсечено M2

  • «ИИ-ассистент закроет 80% рутины» — реальность: 4 функции Telegram-бота, букинг вручную
  • Полный уход от агрегаторов — цель: диверсификация, не отказ
  • Прыжок сразу в премиум 50 тыс. — промежуточная ступень: средний-плюс 25–40 тыс.

Снято с повестки 2026: обучающий продукт «как открыть лофт», франшизное направление в регионы, готовая трёхуровневая продуктовая сетка (нет в реальности — почасовка).

Раздел 9

Что попадает в M3-02 и далее

Мостик из стратегической картины в следующие модули.

M3-02

Архитектура линейки — без обсуждения

  • Архитектура «событие × вариант» 5 × 2 = 10 SKU
  • Корпоративный пакет 60–90 тыс. ₽ как якорь линейки
  • Нижняя граница — 28–30 тыс. ₽ (не ниже Memory Place)
  • Партнёрская экосистема 5–8 подрядчиков, агентские 10–20%
  • Welcome-пакет (шампанское/декор/час) как стандарт от 30 тыс.
  • Открытое меню допуслуг с фиксированными ценами
  • Динамика прайса по дням (будни / Вс / Пт-Сб)
  • Приоритет 2–3 SKU на Q2-Q3 — на данных AmoCRM
M4

Аудитория — открытые вопросы

  • Массив сделок 50+ тыс. (8.2 п.6) → разбор премиум-сегмента
  • Массив повторных клиентов (8.2 п.7) → 5–10 коротких интервью
  • Замер реальной структуры базы по 5 сегментам (M2-03 + AmoCRM)
  • Все сегменты в работе — приоритет по «до чего дотянуться можем»
M5

Конкуренты-углубление

  • Гео-картина района Бауманской/Семёновской — реальные соседи по 11 лофтам
  • Какой из 11 лофтов даёт лучшую заполняемость (AmoCRM п.3)
  • Проверка апсельной формулы +30–40% на 2-3 игроках помимо Soxspace
M6

Позиционирование

  • «Турки-проводник» — камерный семейный + B2B-формат под ключ средний-плюс
  • «Местный лидер района Бауманской» как геопроявка
  • Тон «спокойная уверенность» без глянца (brand/voice-style.md)
M7

GTM — структура воронки

  • 50% агрегаторы + 30% прямые (сайт + Telegram + Я.Карты) + 20% B2B-агентства
  • Стандарт первого ответа за 15 мин через Telegram-бот (4 функции)
  • B2B-документы: переупаковка в презентационный PDF-пакет
  • Первая версия сайта с прямой бронью + список причин удержания депозита
M8

Контент-стратегия

  • Telegram-канал «Лофт-пространство / район Бауманской»
  • Контент через кейсы, цифры, отзывы — без личного бренда Юли (норма рынка)
  • Telegram-рассылка по сегментированной базе AmoCRM
  • Пустые ниши: YouTube-туры по лофтам, SEO-блог про выбор лофта
