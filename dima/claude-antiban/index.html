0. Фундаментальный принцип: Накопительный риск-скоринг

Anthropic практически никогда не блокирует аккаунт из-за одной изолированной причины. Система контроля рисков анализирует цепочку цифровых сигналов и суммирует показатели:

Risk Score = f(IP / Хостинг) + f(Single-IP Handshake) + f(Режим TUN) + f(Таймзона) + f(Изоляция) + f(Телефон) + f(Платёж) + f(Нагрузка)
Суть защиты: Приведение в порядок сигналов на каждом этапе стека. Если накапливается пороговое значение нестыковок (например: датацентровый пул IP + видимый системный прокси + несовпадение IP при авторизации), аккаунт мгновенно блокируется.

1. Архитектурный сдвиг: «Тонкий клиент (Mac) → Сервер в США 24/7»

Запуск Claude Code локально на MacBook имеет критические ограничения: при закрытии крышки агент засыпает, обрывая длинные сессии кодинга, парсинг, ночные генерации и Telegram-ботов. Кроме того, постоянные смены домашних/офисных Wi-Fi сетей вызывают подозрения антифрода.

┌─────────────────────────────────┐ │ MacBook (Клиент) │ │ - VS Code (Remote - SSH) │ ◄── Тонкий терминал управления │ - Браузер (Изолированный) │ └────────────────┬────────────────┘ │ Зашифрованный туннель SSH (ed25519) ▼ ┌─────────────────────────────────┐ │ VPS в США (Ubuntu 24.04) │ ◄── Статический чистый IP (Дата-центр США) │ - Claude Code (24/7) │ ◄── 1 Gbps канал без сна и лимитов крышки │ - Docker / Фоновые демоны │ ◄── Ночные конвейеры, парсинг, боты │ - SOCKS5 / VLESS прокси-мост │ └────────────────┬────────────────┘ │ HTTPS / WebSocket (Напрямую к API) ▼ ┌─────────────────────────────────┐ │ Anthropic API / Claude.ai │ ◄── Видит 100% стабильного американского юзера └─────────────────────────────────┘

Требования к серверу:

  • Провайдеры: HostHatch или BandwagonHost (дата-центры: Los Angeles / Silicon Valley / New York).
  • Конфигурация: KVM NVMe, 8–16 GB RAM, 4+ vCPU, чистая ОС Ubuntu 24.04 LTS.
  • Установка агента: Claude Code разворачивается непосредственно на сервере через расширение VS Code Remote - SSH (команда Install in SSH: root@studio-vps).
  • Преимущество: Ноутбук используется исключительно как монитор и клавиатура. Вся тяжёлая работа крутится непрерывно.

2. Решение «Тонкого места»: Авторизация через зеркальный IP (Single-IP Handshake)

Главная точка уязвимости распределённой архитектуры — момент первичной OAuth-авторизации в браузере (claude.ai/oauth/authorize).

В чём ловушка: Терминал Claude Code запущен на сервере в США и генерирует одноразовую ссылку авторизации. Вы кликаете по ссылке на Mac, и браузер открывает страницу входа. Если на Mac включен сторонний VPN или соединение идёт напрямую, Anthropic видит, что сессия запрошена из дата-центра США, а подтверждается браузером из другой страны. Это моментальный красный флаг фрод-скоринга!

Инженерное решение (Single-IP Handshake):

Перед кликом по ссылке авторизации трафик браузера на Mac временно пускается через сам удалённый сервер:

  1. Поднятие SOCKS5-прокси через существующий SSH-туннель: 
    ssh -D 10808 -N -f root@studio-vps
  2. Маршрутизация браузера: Через системные настройки или расширение (SwitchyOmega / FoxyProxy) направьте трафик доменов claude.ai и anthropic.com на socks5://127.0.0.1:10808.
  3. Результат: Запрос авторизации в браузере уходит ровно с того же самого IP, на котором запущен терминал Claude Code. Показатель риска при авторизации равен 0. После входа туннель можно закрыть.

3. Протокол изоляции мультиаккаунтов (Multi-Account Segregation)

Если у вас уже есть первый рабочий аккаунт (например, локальный или зарегистрированный через СНГ/Узбекистан), и создаётся второй «чистый» аккаунт на максимальный тариф (\$100/мес Max):

Категорический запрет на пересечение сессий: Один общий HTTP-запрос или пересечение куки свяжет оба аккаунта в графе антифрода, и бан одного аккаунта автоматически уничтожит второй.

Правила строгого разделения:

  • Сетевая изоляция: Новый чистый аккаунт никогда не должен открываться под IP-адресами старого аккаунта, и наоборот.
  • Изолированные профили браузера: Создайте в Google Chrome отдельный профиль (например, «Claude USA Pro») либо используйте отдельный чистый браузер (Brave / Safari). В нём не должно быть истории, сессий или расширений старого аккаунта.
  • Раздельные хранилища токенов: На Mac не держите токены нового аккаунта в системной связке ключей. Новый аккаунт должен жить исключительно в файловой системе удалённого VPS (директория /root/.claude/), к которой у локальных программ нет прямого доступа.

4. Сетевая инфраструктура, TUN и Kill Switch

Если агент или веб-интерфейс используются на Mac, применяются строгие правила маскировки:

4.1. Обязательный режим TUN

Обычный системный прокси прописывает в macOS адрес 127.0.0.1:7890. Claude Code считывает сетевой профиль и видит проксирование. Режим TUN поднимает виртуальную сетевую карту на уровне ядра ОС. Трафик перехватывается прозрачно, а системный прокси остаётся чистым (scutil --proxy возвращает 0).

4.2. Kill Switch и запрет отката в Direct

Правило сброса соединения: Если туннель к серверу кратковременно оборвался, трафик доменов claude.ai, claude.com, api.anthropic.com должен сбрасываться (REJECT). Автоматический откат в DIRECT недопустим.

5. Готовые скрипты автоматизации (Из репозитория agent-server-hub)

Для быстрого и безошибочного развёртывания всей инфраструктуры используйте готовые скрипты:

5.1. Настройка SSH на Mac (`setup_ssh.sh`)

Автоматически генерирует надёжный ключ ed25519, пробрасывает его на сервер через ssh-copy-id и создаёт защищённый alias в ~/.ssh/config с параметрами ServerAliveInterval 60 и ForwardAgent yes. 

cd ~/studio/Gemstudio/agent-server-hub/scripts
./setup_ssh.sh <IP_АДРЕС_СЕРВЕРА>

5.2. Инициализация сервера (`bootstrap_server.sh`)

Запускается на сервере Ubuntu 24.04 LTS: настраивает фаервол ufw, защиту fail2ban, устанавливает Node.js 20 LTS, Python 3.11+, Docker, ffmpeg, создаёт безопасную структуру /root/projects и файл .env с правами chmod 600. 

ssh studio-vps "bash -s" < ~/studio/Gemstudio/agent-server-hub/scripts/bootstrap_server.sh

5.3. Скрипт проверки чистоты окружения Mac (Bash)

# 1. Системный прокси macOS — все значения должны быть 0
scutil --proxy | grep -E "HTTPEnable|HTTPSEnable|SOCKSEnable"

# 2. Переменные окружения текущего shell
env | grep -iE "proxy"

# 3. Наличие proxy в файлах запуска shell
grep -iE "proxy" ~/.zshrc ~/.bashrc ~/.profile ~/.zshenv 2>/dev/null

# 4. Конфигурация пакетных менеджеров npm / git
npm config get proxy 2>/dev/null
git config --global --get http.proxy

# 5. Конфигурация Claude Code и переменные Anthropic
cat ~/.claude/settings.json 2>/dev/null | grep -iE "proxy|base_url|anthropic_"
env | grep -iE "anthropic|claude"

# 6. Проверка внешнего IP и геолокации
curl -s https://ipinfo.io | grep -E "ip|country|region|city"

6. Способы оплаты и Платёжный хак «Сингапурский шлюз»

Платёжный метод — ключевой триггер антифрода Stripe и Anthropic. Оплата российскими картами или популярными массовыми виртуалками гарантированно ведёт к бану.

Платёжный хак: «Сингапурский шлюз через Apple ID» (Наивысший траст)
Связка: Сингапурский Apple ID + Сингапурская карта (Starryblu) + In-App Purchase в приложении Claude на iPhone.

Почему это работает на 100%: Платёж принимает корпорация Apple (Merchant of Record). Данные банковской карты, имя владельца и BIN-код не передаются в Stripe и Anthropic. Фрод-фильтр банковских карт Anthropic вообще не активируется!

Правило совпадения триады (100% консистентность):

Apple ID (Сингапур) ≡ Карта оплаты (Сингапур) ≡ VPN на телефоне (Сингапур)

В момент подтверждения покупки по Face ID на iPhone должен быть включен сингапурский узел. После этого аккаунт получает легальный Pro/Max статус и подключается к американскому серверу.

Другие проверенные способы оплаты:

  1. Банковская карта США: Личная карта американского банка или карта зарегистрированной US LLC.
  2. US PayPal через US Apple ID: Американский аккаунт PayPal, привязанный к Apple ID.
  3. Физическая карта Starryblu напрямую: Оформить карту Starryblu | Инструкция @gkxspace.
  4. Подарочные карты Apple (Gift Cards): Фотоинструкция от @zureA255062.
  5. Сводная база альтернативных методов оплаты: Коллекция от @Nemo001ai.

7. Системные настройки, телефон и профиль

7.1. Телефонный номер

  • Запрет виртуальных SMS-хабов: Разовые номера помечаются антифродом как высокорисковые.
  • Решение: Постоянная американская eSIM/SIM от Red Pocket (\$30/год) в связке с картой-адаптером BeeSIM (работает в любом смартфоне): Инструкция по Red Pocket + BeeSIM.

7.2. Электронная почта

  • Использовать чистый или старый личный Gmail. Избегать свежерегов Outlook и покупных почт.

7.3. Таймзона и геолокация (macOS & iOS)

  • В системных настройках «Дата и время» отключить автоопределение и вручную выставить часовой пояс сервера (US / Pacific).
  • В «Конфиденциальность и безопасность» → «Службы геолокации» → «Системные службы» отключить «Установка часового пояса».
  • В профиле Claude (Settings → Privacy) отключить Location metadata и Help improve our AI models.
